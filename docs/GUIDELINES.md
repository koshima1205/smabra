# ガイドライン確認メモ（CNP・CryptoNinja）

本作が CNP（CryptoNinja Partners）と CryptoNinja のガイドラインに沿っているかを確認した記録です。
**最終確認: 2026-09-26**（各ページの本文を読んで確認）。規約は変わることがあるので、公開範囲を広げる前や収益化を考えるときは読み直してください。

**結論**: 個人の趣味の非営利ファンゲームとして公開する範囲で、ガイドラインに沿っている（タイトルは確認の結果「CNP乱舞」から「月下乱舞」に改名した）。販売・収益化や会社としての利用をするなら、先に CNP とのライセンス契約が必要。

月蝕綺譚（Studio VIBE）は別の権利者で、別の[二次創作ガイドライン](https://vibe.co.jp/luna-occulta/fanworks)があります（このメモの対象外）。

## ガイドラインの要点

- **CNP と CryptoNinja は別の IP**。CNP の個人の二次創作は「基本的に CryptoNinja のガイドラインに準じる」うえで、CNP 独自の注意事項がある。
- **利用条件**（ライセンスガイドライン）:
  - 非商用: 個人（NFT ホルダー・非ホルダーとも）OK
  - 商用: ホルダー個人 OK／非ホルダー個人・法人は審査または契約が必要（審査制は 1 キャラ年 5 万円〜）
  - 法人（または法人に準じると判断された個人）は、ライセンス契約を結んで使う（二次創作ガイドライン「法人利用について」）
- **ブランドと誤認**: CNP というブランドを自由に使ってよいわけではない（例:「CNP学習塾」のような事業は無断ではできない）。公式と誤認される「コラボレーション」「パートナーシップ」等の表現は使わない。公式との混同を防ぐ配慮をする。
- **AI**: 素材屋CNP のイラストや CNP の NFT 画像を AI に読み込ませてよいのは**合計 10 点まで**（AI に生成意図を理解させる目的に限る）。11 点以上の一括利用・学習・生成ツールづくりは NG。AI で作ったものの権利は、基本的に元のイラストの制作者に残る。NFT 画像からの生成物は SNS 等での発信に限り、販売・商品化はできない。
- **使えない素材**: 公式サイトのメインビジュアル（キャラ集合イラスト）は AI 利用も素材利用も不可。素材屋CNP のイラストは加工・トレース不可、素材そのものの再配布・販売も不可。
- **禁止事業**: ふるさと納税 NFT・トレーディングカード（「トレカ」を連想させる名前との組み合わせも不可）。
- **CryptoNinja 共通の禁止事項**: イメージを損なう内容／他者の権利を侵害する（おそれのある）内容／公式と誤解を招く内容／二次創作をその作者に無断で再利用（トレース・AI への読み込みなど）／過剰な性的・猟奇的表現や中傷。
- 判断が難しいときは CNP 運営に問い合わせる（Discord の NinjaDAO「cnp問い合わせ」）。

## 本作の確認結果

| 項目 | 結果 | 内容 |
| --- | --- | --- |
| 非営利のファンゲームとして CNP 9体を 3D 化して公開 | OK | 非商用の個人利用は OK。CNP キャラを使った描き下ろし・オリジナルの作品作りは自由とされ、3D 化の制限はない |
| 販売・収益化 | しない | 非ホルダーの商用利用は審査・契約が必要。さらに、AI に読み込ませて寄せた見た目は販売・商品化に向かない。広告・投げ銭・有料配布も収益化にあたるので入れない |
| 素材屋CNP のイラストの AI 利用 | OK（10 点中 9 点） | 1 体 1 点・合計 9 点（残り 1 点）。イラストはリポジトリにもゲームにも入れていない（git の全履歴で確認）。トレースなし。メインビジュアル・NFT 画像・スタイルガイドは使っていない |
| 公式と誤認される表現 | OK | 「コラボ」「パートナーシップ」等は使っていない（ゲーム内の「パートナー」は設定上の相棒の意味）。タイトル画面・クレジット・README・ページの説明に「非公式」。ロゴの下は「CRYPTONINJA PARTNERS RANBU」をやめて「非公式ファンゲーム」にした |
| タイトル | OK（改名済み） | 公式の商品・サービスは「CNP○○」の名前が多く（公式の対戦ゲーム「CNPバーニンウォーズ」、CNPトレカ、CNP Friends など）、旧タイトル「CNP乱舞」はその並びに見えた。「ブランドを自由に使ってよいわけではない」「公式との混同を防ぐ配慮」に触れるおそれがあったので、2026-09-26 に「月下乱舞」に改名。CNP の名前は説明（「CNP と月蝕綺譚の〜」など）にだけ使い、タイトルには入れない |
| イメージ・表現 | OK | CNP 9体のワザ名・説明文を確認。流血・残酷・性的な表現はない。ミタマの「丑の刻参り」「藁人形の呪い」はパートナーの忍者（瀬織）の忍術から。公式にも対戦ゲームがある |
| 他者の権利 | OK | CNP のイラスト・ロゴは使っていない。NINJAMCP からは事実情報（名前・クラン・忍術・得物など）だけを保存し、出典を表記。月蝕綺譚のモデル・設定は同作の二次創作ガイドラインの許可の範囲で使っている。任天堂の固有の名前・決め台詞は削除済みで、「スマブラ」を連想させたリポジトリ名 `smabra` も `gekka-ranbu` に変えた |
| 禁止事業 | OK | トレカ・ふるさと納税 NFT ではない |
| 個人か法人か | OK | 個人の趣味の非営利作品として公開している。会社の業務・PR・デモとして出すなら法人の利用にあたり、ライセンス契約が前提になる |
| 権利表記 | OK | 「キャラクターの権利は各権利者に帰属（CNP: © CryptoNinja Partners ／ CryptoNinja: © Ninja DAO）」と、CNP のガイドラインへのリンクをクレジットと README に記載。CNP のモデルの見た目は素材屋CNP のイラストからなので「本作オリジナル」とは書かない |
